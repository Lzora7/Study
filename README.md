# Study — Data Science Portfolio

Учебное портфолио Виталия Караулова по **Data Science**: классическое машинное обучение, глубокие нейронные сети, NLP и LLM, компьютерное зрение, генеративные модели и обработка звука. Основная часть — работы программы «Искусственный интеллект» НИУ ВШЭ: от экспериментов с моделями и оценки качества до разработки Python-сервиса.

## Как изучать и запускать

Ноутбуки `.ipynb` можно просматривать прямо на GitHub. Для выполнения откройте нужную работу в Jupyter или Google Colab и ознакомьтесь с ячейками установки зависимостей и загрузки данных.

Каждый проект использует собственное окружение: единого набора зависимостей для всего репозитория нет. Для сервисов и ASR инструкции находятся в соответствующих README. Датасеты и веса могут требовать отдельной загрузки; пути к данным и параметры окружения нужно адаптировать под свою машину. Для обучения нейросетей может потребоваться GPU.

Это учебные работы: ноутбуки содержат исходные формулировки заданий, предоставленные материалы и решения. Численные результаты и выводы следует смотреть в самих работах; запуск всех проектов в едином окружении не проверен.
