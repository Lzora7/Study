# Синтез музыки методами DSP

Генерация звуков музыкальных инструментов и сборка композиции без использования нейронных сетей.

## Задачи и реализация

- Аддитивный синтез звука.
- Физическое моделирование по алгоритму Карплуса — Стронга.
- Частотная модуляция — FM-синтез.
- Сборка и сохранение музыкальной композиции в WAV.

Основные реализации находятся в `additive.py` и `ks_fm.py`. Эксперименты и прослушивание результатов — в [hw1.ipynb](hw1.ipynb).

## Технологии

Python, NumPy, SciPy, Matplotlib, Jupyter, IPython Audio.

## Запуск

Из корня репозитория:

```bash
cd AI-HSE/Sound/HW_1
python3 -m venv .venv
source .venv/bin/activate
pip install numpy scipy matplotlib notebook
jupyter notebook hw1.ipynb
```

Выполните ячейки ноутбука последовательно. Запускайте его из каталога проекта, чтобы были доступны локальные модули и папка `Melodies/`.

## Результат

Ноутбук содержит визуализации и аудиопримеры. Итоговая композиция сохраняется в `own_composition.wav`.
