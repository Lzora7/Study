# Audio & Speech Processing

Учебные проекты по цифровой обработке звука, распознаванию и синтезу речи в рамках программы «Искусственный интеллект» НИУ ВШЭ.

| Проект | Задача | Основные технологии |
| --- | --- | --- |
| [Синтез музыки](HW_1/README.md) | Генерация звуков инструментов и музыкальной композиции | NumPy, SciPy, Matplotlib |
| [Распознавание речи](HW_2_dpspch/README.md) | Преобразование аудио в текст, оценка WER/CER | PyTorch, torchaudio, Deep Speech 2, CTC, Hydra |
| [Нейронный вокодер](HW_3/README.md) | Восстановление аудио по mel-спектрограммам | PyTorch, iSTFTNet, GAN, librosa, Hydra |

Каждый проект запускается из собственного каталога и использует отдельное виртуальное окружение. Команды ниже в проектных README предполагают запуск из корня репозитория Study.

[HW_2](HW_2/README.md) — исходный учебный шаблон ASR с незавершёнными компонентами. Для знакомства с реализацией распознавания речи используйте HW_2_dpspch.
