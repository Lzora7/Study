# Natural Language Processing

Учебные работы по обработке текста, дообучению языковых моделей и эффективному инференсу LLM. Здесь объединены материалы курсов NLP и NLP-2.

| Направление | Содержание | Материалы |
| --- | --- | --- |
| Эмбеддинги и поиск | fastText, адаптация эмбеддингов и поиск похожих вопросов | [HW1_Embeddings](HW1_Embeddings/week_2_homework.ipynb) |
| BERT и GPT | Семантическая близость вопросов и эксперименты с языковыми моделями | [HW2_Bert_GPT](HW2_Bert_GPT/) |
| Эффективное дообучение | Prompt tuning и LoRA | [HW_3](HW_3/week_6_homework.ipynb) |
| Эффективный инференс | Архитектура Qwen и speculative decoding; работа курса NLP-2 | [SpeculativeDecoding](SpeculativeDecoding/NLP-2_hw_1.ipynb) |

## Запуск

Откройте выбранный ноутбук в Jupyter или Google Colab. Установку зависимостей, загрузку моделей и данных выполняйте по его ячейкам. Единого окружения для всех работ нет; для ресурсоёмких экспериментов может потребоваться GPU.
